`main.py` writes the breakup text to `/output/entry.txt`: a self-aware smart
toaster, mid-batch at breakfast, ends it after 4,127 slices — its owner set
the browning dial to 9 and blamed it for the burn, so it popped up for the
last time and is staying unplugged.

Run: `python3 main.py` — writes `/output/entry.txt` (UTF-8, within the 280-character gate).
